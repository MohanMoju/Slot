# 🎰 Unity Slot Machine Game

## 📖 Game Overview

This project is a basic Slot Machine Game developed using Unity and C#.

The player interacts with the slot machine by pulling a lever. When the lever is pulled, three reels spin and stop with randomly generated symbols.

The player wins when all three reels display the same symbol.

### Features

- 🎰 Three slot reels
- 🕹️ Lever-based gameplay
- 🎲 Random Number Generation (RNG)
- 🔄 Smooth reel spinning animation
- 🏆 Winning combination detection
- 💰 Payout system
- 💵 Balance and betting system
- 🎉 Jackpot for matching symbols
- 🎨 UI-based slot machine design

---

## 🎮 How to Play

1. Start the game.
2. The player begins with a balance of **1000**.
3. The bet amount is **100**.
4. Pull the lever to start the game.
5. The three reels begin spinning.
6. The reels stop one after another.
7. If all three symbols match, the player wins.
8. If the symbols do not match, the player can try again.

---

## 🏆 Winning Conditions

The player wins when all three reels display the same symbol.
